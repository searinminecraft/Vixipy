Vixipy [vick-see-pie] is a free, open source, and cross-platform
pixiv client for the web. It allows you to use pixiv and enjoy
works without worrying about prying eyes.

## Use Vixipy

See the [instance list](https://maid.zone/vixipy/instances.html)

## Installation

Installing Vixipy is as easy as following these simple
[instructions](./doc/INSTALL.md).

## Compatibility

Vixipy has been confirmed to run on the following operating systems:

* Windows
* Linux
* FreeBSD
* Haiku
* Debian GNU/Hurd
* Android

Others not listed above *might* be supported, as long as your
operating system has decent support for Python 3.10 and above
and has a working compiler.
